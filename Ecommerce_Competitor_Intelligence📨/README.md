# E-Commerce Competitor Intelligence & AI Pricing Engine

An automated ETL and market analysis pipeline built in Python. This tool ingests target e-commerce catalog data, calculates relative pricing disparities against internal SKUs, and leverages Groq's high-speed LLM endpoint (`openai/gpt-oss-120b`) to generate actionable executive briefing reports.

## 🚀 Business Value
* **Margin Optimization:** Identifies underpriced and overpriced inventory automatically.
* **Competitor Intelligence:** Tracks stock status and rival price points at scale.
* **Executive Decision Support:** Replaces manual spreadsheet analysis with instant AI market summaries.

## 🛠 Tech Stack
* **Language:** Python 3.x
* **Data Processing:** Pandas, OpenPyXL
* **AI Analysis:** Groq REST API (`openai/gpt-oss-120b`)
* **Export Formats:** CSV, Excel (`.xlsx`), Text (`.txt`)
